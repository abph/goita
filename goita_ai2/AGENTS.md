# AI強化の作業方針

人間と方針が確定したAIの戦略修正は、以下を一組として扱う。

1. 元レポートを再現し、実際の理由・候補評価を調べる。方針の確認は既存の会話で合意済みなら繰り返さない。
2. 特定棋譜専用の規則を避け、汎用的に修正し、既存戦略との競合と説明ログを確認する。対象は強化中AI2。保存版の中級者AIは明示指示がない限り変更しない。
3. 回帰テストを追加し、AI判断チェックに、ユーザーが確定した最善手・許容手・避けたい手・理由を登録する。現AIが選んだ手を自動的に正解にしない。
4. `python -m goita_ai2.neural_review_materials sync` で確定回答をニューラル教材にも登録し、`check` で登録漏れ・古い正解がないか確認する。
5. 関連テストと必要なAI判断チェックを実施し、使用した旨と結果をユーザーに報告する。教材に追加した局面数と受け・攻めを分けた判断データ数も報告する。

誰かの初期手駒が5し以上の局は教材にしない。安全思考とリスク思考は分離し、未確認・保留・参考の判断を勝手に確定しない。

「教材への登録」と「再学習してモデルへ反映」は別工程。モデルへの自動反映は行わず、依頼された場合に現行モデルを保存した別モデルで再学習し、未学習局面も含めて比較してから採否を決める。教材同期だけで「学習済み」「強くなった」と報告しない。

レポート不足などで教材化できない場合は、未登録の対象と理由を具体的に残し、ユーザーに報告する。詳細は `NEURAL_REVIEW_MATERIALS.md` を参照。
