# ごいたAI 指導データ

これまでの棋譜への指摘を、AI本体から独立して保存するための資料です。
現時点では学習用入力ではなく、戦略の確認、実装設計、悪手回帰テスト作成の基準として使います。

## 状態

- `confirmed`: 方針が確定している。回帰テストとAI判断へ接続する対象。
- `reference`: 局面依存が大きい、または結論を保留した参考事例。
- `superseded`: 後の指摘で置き換えられた旧方針。AIへ再導入しない。

## 重要度

- `critical`: 確定上がりの見落とし、相手の即上がりを許すなどの明らかな悪手。
- `high`: ペア戦の合図や強い定石を壊す手。
- `normal`: 勝率や得点を改善する打ち方。

## ケースの読み方

- `conditions`: この方針を適用するための条件。
- `required`: 必ず満たす判断。具体的な駒が一つに決まらない場合もある。
- `preferred`: 条件が同じなら優先したい手順。
- `forbidden`: 避ける手や、旧AIが選んだ悪手。
- `reason`: 人間側から示された戦略上の理由。
- `regression`: 自動テストへの接続状況。`pending` は今後のテスト候補。

新しい指摘は、まず既存ケースと重複・矛盾しないか確認します。既存方針の訂正なら古いケースを削除せず、`superseded.yaml` へ移して置換先のIDを記録します。

## 思考の種類

- `safe`: 現在の強化対象。確定上がり、失敗時の損失、敵の即上がり回避を優先する。
- `risk`: より高い得点を狙って安全な得点を一部手放す考え方。`risk_strategy.yaml` に別系統で保存し、現在のAIや安全思考のニューラル補正へは接続しない。

思考の種類がない過去のレポートと補正データは、互換性のため `safe` として扱います。

## 現行AIの監査

棋譜つきの15件は、次のコマンドで現在の強化中AIへ再度判断させられます。

```powershell
python -m goita_ai2.instruction_case_audit
```

監査は棋譜を合法手として再現し、受けを選んだ場合は直後の攻めまで確認します。
AIの戦略は変更せず、指導内容どおりに動く件数と、まだ異なる件数を表示します。
