## 遊び方

1. VRChat側でA席へ参加し、STARTを押す。
2. サイトの人が `https://solo.vrcgoita.com/?room=vrc-solo-table1` を開く。
3. B・C・Dのうち参加したい席の「参加・再接続」を押す。1人1席で、各席は先着1人。開始前なら退出して別の席を選び直せる。
4. VRChat側で参加者がそろったことを確認し、もう一度STARTを押す。空席はAIで埋まる。サイト参加者が0人でも開始可能。
5. A・Cチーム対B・Dチームで対局する。CはAの味方、B・DはAの対戦相手になる。開始後は新規参加できず、残りの人は観戦する。
6. 終局後はVRChat側のNEXT ROUNDで続行。各席の参加者・名前・点数を維持する。NEW MATCHでは点数をリセットし、参加者は維持する。
7. 終了はVRChat側の「利用終了」を10秒以内に二度押す。

Room IDを変更している場合、リンク末尾の`table1`を設定したIDに合わせてください。URLは参加権を限定する認証リンクではありません。開始後のAI席に人間が新しく入るには、VRChatで利用終了して新しく参加待ちを開始してください。

## 同期と秘密情報

- サーバーが対局の正本。空席だけをAIへ割り当て、サイトの着手後もサーバーがAIの手番を進める。観戦者のCPUリクエストには依存しない。
- サイト側の手番・参加待ち中などにVRChat所有者が約6秒間隔で状態を取得し、同じインスタンス内へ同期する。通信時間やUdonの通信待ちが加わるため即時反映ではない。
- 同じ盤面の取得ではA席の駒選択を解除せず、出した手駒の隙間も維持する。
- 対局中、サイトには各席の本人の手駒だけを送り、VRChatにはB・C・Dの残り枚数だけを送る。伏せ駒とログからの秘密情報流出も防ぎ、終局後に全員の手駒・伏せ駒を公開する。
- サイトからのA席着席、複数席の同時取得、AI設定変更、開始、リセット、手駒の強制公開を拒否する。
- ブラウザの`client_id`は既存サイトと同じ端末識別方式。アカウント認証ではない。VRChatのURL内識別子も認証用の秘密鍵ではない。

## 切断・交代

- サイトは6秒間隔で本人の席だけの生存確認を送る。30秒以上確認できなければその席だけ再接続待ち表示になる。
- 最後の確認から120秒は席を保持。同じブラウザの再読み込みで復帰可能。別ブラウザや別端末への引き継ぎは初版では未対応。
- 120秒経過後も自動でAIにはせず、A席が該当するB → AI・C → AI・D → AIを10秒以内に二度押して、その席だけを交代する。
- 対局中に本人がサイトで退出した場合は、待ち時間なしでAIへ交代可能。開始前の退出では、その席を再び空席にして別の人も参加できるようにする。
- 参加待ち中にAI交代ボタンを使うと対象の席をAIへ予約する。対局開始は別途STARTを押す。通常は参加者がそろったところでSTARTするだけで空席をAIにできる。
- AIへ交代するとその利用が終わるまで対象の席はAIのまま。再び人間を参加させるにはVRChatで利用終了し、STARTで新しく開始する。他の席の参加者は交代操作の影響を受けない。
- サイトからの生存確認はVRChat側の使用権を延長しない。VRChatの通信が途絶えて180秒経過するとサイト側も終了表示になり、別インスタンスが利用可能になる。
- 利用終了・サーバー再起動・新しい使用者への交代後に、古い席の操作は継続できない。

## 検証

```text
python -m pytest tests/test_vrc_solo_bridge.py tests/test_vrc_solo_coop.py tests/test_vrc_solo_multiseat.py -q
node tests/vrc_solo_coop_ui_behavior.cjs
node tests/vrc_solo_multiseat_ui_behavior.cjs
node tests/immediate_actions_ui_behavior.cjs
node tests/hand_rehide_ui_behavior.cjs
```

テストは専用のSQLiteファイル・仮想HTTPクライアントを使用し、公開対局を変更しません。ブラウザテストにはPlaywrightとEdgeが必要です。3つの独立したブラウザ利用者での着席・着手・秘密手駒・再接続、B/D席が人間の対局と4人人間での終局を検証します。Unityでは確認用プロジェクトでUdonコンパイル、36本URL生成、3つの席別交代ボタン、更新メニュー再実行、未変更ポーリング時の駒選択保持を確認します。実際のVRChatと公開サイトをまたぐ実機対局は、デプロイとワールド更新後に確認してください。
