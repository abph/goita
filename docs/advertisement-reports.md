# 広告の実績を見る

管理者ページの「地域別広告」は、最初に「広告の実績」を表示します。

- 集計期間は直近30日が初期値です。直近7日・全期間にも切り替えられます。
- 表示回数・クリック数・クリック率を全体と広告別に比較できます。表の見出しで並べ替えられます。
- 広告名を押すと、日別グラフ、日別の表、表示場所別・地方別の内訳を表示します。
- 登録・編集・ツイプラ取り込み・プレビューは「広告の設定」にあります。

## 数値の意味

日付は日本時間です。直近7日・30日は今日を含みます。登録中の広告を集計し、停止中・掲載終了の広告も含みます。削除した広告は含みません。

クリック率はクリック数÷表示回数×100です。全体のクリック率も合計から計算し、広告別クリック率の単純平均にはしません。表示回数が0のときは「—」です。

既存の計測方法を使用します。表示回数には画面外での表示処理も含まれ、同一広告・同一ブラウザーでは1日最大3回まで計測します。自動スライドは表示回数に含めませんが、クリックは計測するため、表示回数が0でもクリックがある場合があります。

「期間内の初回表示ブラウザー」は、その広告を初めて表示したブラウザーの記録数です。期間中に再訪した全ブラウザー数ではありません。全期間でも計測開始以降の概算です。ブラウザーの保存データ削除などにより増えることがあり、人数とは異なります。広告間で合算して全体の閲覧者数としては表示しません。

表示場所別の計測開始より前の記録は、全体や地方別に含まれていても、表示場所別には含まれません。既存データの削除や新しい個人情報の収集は行いません。

## 実装・確認

管理者専用の `GET /admin/api/regional-ads/report?period=7|30|all` で既存の集計テーブルを読み取ります。設定保存用APIや既存の累計APIの契約は維持しています。

`tests/test_regional_ad_report.py` で期間境界・日本時間・内訳・クリック率・認証を、`tests/regional_ad_report_ui.cjs` で管理画面の操作とPC・モバイル幅を確認します。UIテストはPlaywrightとChromiumを使用し、必要なら `EDGE_PATH` でEdgeを指定できます。HTTP応答はすべてテスト内で置き換えるため、本番へアクセスしません。
