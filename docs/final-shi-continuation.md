# 強化中AI2：し攻めの3回目

相方がしで攻め、自分もしを2回続けたとき、直前のしが一巡したなら、その公開情報を最後のしの判断にも使う。敵方にしがわずかに残ると推定していても、残りしの推定と公開手順を確認し、王か玉に止められ得る通常の攻めより、しを優先する。従来の確定上がりや、敵方の残りしが0枚と強く推定できる場合の処理はそのまま使う。誰かがリーチなら従来の終盤評価に任せる。

最後のしを出す場合は、残り2枚で一巡後に何点取れるかと、しを受けられた後にどの種類で受けて上がれるかを別々に見る。安全思考は後者の種類数を、リスク思考は一巡後の得点を優先する。受けの候補は公開済みの駒と推定から求め、他家の非公開手駒は参照しない。

強化中AI2は安全思考が初期値。デバッグルームの対局設定 → 自動進行・AI検証 →「強化中AI2：終盤のし攻め」で、この判断に限り切り替えられる。中級者（中3）や他のAI、およびスコアアタックで使うAIは変更しない。

回帰棋譜 `goita_kifu_score-oK` の残り「し・馬・金・金」では、安全思考は金を伏せてしを出し、馬・金で受けられる形を残す（一巡で30点）。リスク思考は馬を伏せてしを出し、金2枚を残す（一巡で60点）。
