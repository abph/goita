# スコアアタック

デバッグルームのメニューだけに「スコアアタック」を表示します。A席の利用者が外部棋譜を選び、対象局を指定して開始します。読み込んだ局の配牌・親・開始時点数を使い、B・C・D席をトレースAIとして自動で進行します。

「50点以下の棋譜からランダムに対戦」では、サーバーに非公開で保存した `kifu_data.json` の局開始時点数がAC・BDともに50点以下の局から1局をランダムに選び、同じ方式で開始します。デバッグルームのA席で、会員・ゲストとも参加できます。元のプレイヤー名・棋譜ID・対局日時は対戦画面へ渡しません。棋譜原本の登録と棋譜ID指定の手札読込は引き続き管理者専用です。

## 非公開データの初回登録

1. コードだけをデプロイします。棋譜JSONはGitへ追加しません。
2. 永続ディスクのマウント先を `GOITA_PERSISTENT_DATA_DIR` に設定します。既存の会員DBなどで設定済みなら追加設定は不要です。
3. `/admin/` に管理者パスワードでログインします。「サイト設定」→「非公開の棋譜データ」で、端末にある `kifu_data.json` を選び「棋譜データを登録」を押します。
4. デバッグルームのA席に入り、ランダム棋譜トレースを開始します。会員ログイン中は会員ID、未ログイン時はHttpOnly Cookieのゲスト識別情報に成績をひも付けます。

保存先は `GOITA_PERSISTENT_DATA_DIR/private-kifu/kifu_data.json`、ローカルの設定なし環境では `private_data/kifu_data.json` です。登録は20MBまでで、再登録は検証後にファイルを置き換えます。通常の再デプロイ時には再登録不要です。バックアップは端末にも保持してください。

ファイル全体のダウンロードAPIは設けません。旧 `/static/kifu_data.json`・`/static/kifu_data_raw.json` も404にします。棋譜ID指定の手札読込も管理者専用APIから指定した1局の手札だけを取得します。リンクに手札を含める既存機能には変更ありません。

対戦そのものは通常のデバッグルームで行うため、観戦者には盤面など通常の対戦情報が見えます。棋譜原本の非公開化は、デバッグルーム自体の非公開化とは別です。

トレースAIは、元棋譜の次の手が現在の合法手に含まれる間は、その手を優先して指します。A席の選択や別の条件によって局面が元棋譜から分岐した場合は、トレースを解除して通常AIへ切り替えます。これは棋譜から得られる手順と選択傾向の再現であり、元プレイヤーの内心や思考理由を完全に再現する機能ではありません。

終局時には、再戦結果のAC・BD累計点数と、読み込んだ棋譜の終了点数との差を表示します。入力された棋譜は解析と対戦開始のためにサーバーへ送信されますが、棋譜ライブラリには保存しません。機能はデバッグルーム専用で、通常ルームのメニューには表示されません。
外部形式で省略されているパスと、1行にまとめられた「受けてから攻める」手は、対局エンジンの手順に展開してから再生します。

## 結果・ランキング

終局をサーバーが確定すると、A席の挑戦者に結果ポップアップを一度表示します。上から「この局の元の点数と今回の点数」「元々の棋譜を見る」「この棋譜のランキング」「同じ棋譜でもう一度挑戦」「別の棋譜に挑戦」の順です。結果表示中は自動次局を停止します。「挑戦履歴・ランキング」で過去の終了済み挑戦を30件ずつ新しい順に確認でき、各記録から結果・元の棋譜・ランキングを開けます。課題番号は表示専用で、原本の棋譜IDは公開しません。挑戦日・対戦日は日本時間の年月日だけを表示します。

改善点は `(今回AC獲得点 − 今回BD獲得点) − (元AC獲得点 − 元BD獲得点)`。開始時の持ち点を除きます。例：元がAC 0/BD 30、今回がAC 40/BD 0なら+70点。棋譜原本の獲得点も手順をエンジンで再生して確定します。

配牌（並び順は無視）・親・開始点数・元の手順が同じ局で比較します。AIはcurrentに統一し、同点は同順位（1位・1位・3位）。標準の「ベスト記録」は、再挑戦・ファイル読込を含む全終了記録から各人の最高改善点を1枠だけ表示します。同じ自己ベストを複数回達成した場合は最も早い挑戦回の記録を採用します。達成した挑戦回数も表示します。

「初回記録」への切り替えもでき、従来の初回開始時に確定した対象記録を使います。途中退出や再挑戦による初回の取り直しはできず、ファイル持込は初回記録の対象外です。過去に練習として保存された結果もベスト記録に反映します。既存DBは自動移行し、履歴・初回区分を保持したまま課題番号と挑戦回数を追加します。会員・ゲストの保存期間は変わりません。

次の参加者はA席へ入って「この部屋と同じ棋譜に挑戦」を押すと、元の手順を取得せず同条件で開始できます。全棋譜を合算する総合ランキングはありません。

「元々の棋譜を見る」はライブラリ共通の盤面描画・再生処理を使用します。終局した挑戦の本人だけが、その1局の匿名化した手順を取得できます。進行中・他人の記録・他の部屋からのアクセスを拒否し、原本全体を公開するAPIはありません。観戦者に通常の対戦盤面が見えることは従来通りです。

保存先は `GOITA_PERSISTENT_DATA_DIR/private-kifu/trace-results.sqlite3`、ローカルは `private_data/trace-results.sqlite3`。既存の永続保存先で自動作成され、データ再登録・追加環境変数は不要です。会員の結果は期限なし、ゲストの結果は各終局から30日、未完了のゲスト挑戦は開始から30日で期限切れです。期限切れは即座に閲覧・ランキング対象から外し、定期処理（1時間ごと）でも削除します。ゲストの不要な識別情報と参照のない棋譜コピーも削除します。閲覧のたびに成績の期限を延長しません。

ブラウザ変更やCookie削除後のゲスト同一性は保証できません。保存期間内に残る同じ棋譜の挑戦履歴がある間は再挑戦扱いです。表示名はランキング表示用で、識別には使いません。会員ID・ゲスト識別子をランキングへ公開しません。ランキングの表示名は、次の挑戦開始時に現在の名前へ更新します。
