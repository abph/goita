# スコアアタック

トップページの「スコアアタックに挑戦する」から本人専用ルームに入ります。ブラウザのURLは変えず、A席に自動着席し、B・C・D席はAIに固定します。席ボタンは操作できません。トップページに「スコアアタック」セクションを設け、タイトル、説明文、左側の「スコアアタックに挑戦する」と右側の「ランキングを見る」の順に配置します。説明文は「棋譜と同じ手駒・親で挑戦する、1人用の対戦モードです。ほかの3席はAIが担当します。元の対局より良い結果を目指し、ランキングでほかのプレイヤーと競いましょう。」と表示します。デバッグルームの既存メニューは動作確認用として残します。開始ポップアップは「50点以下の棋譜からランダムに対戦」を主な操作とし、その下に「挑戦履歴・ランキング」を配置します。ファイルからの対戦開始と「この部屋と同じ棋譜に挑戦」は表示しません。選ばれた局の配牌・親・開始時点数を使い、B・C・D席はAIが担当します。対戦画面でB・C・D席のプレイヤー名は空欄にします。

「50点以下の棋譜からランダムに対戦」では、サーバーに非公開で保存した `kifu_data.json` の局開始時点数がAC・BDともに50点以下の局から1局をランダムに選び、同じ方式で開始します。会員・ゲストとも参加できます。元のプレイヤー名・棋譜ID・対局日時は対戦画面へ渡しません。棋譜原本の登録と棋譜ID指定の手札読込は引き続き管理者専用です。

## 非公開データの初回登録

1. コードだけをデプロイします。棋譜JSONはGitへ追加しません。
2. 永続ディスクのマウント先を `GOITA_PERSISTENT_DATA_DIR` に設定します。既存の会員DBなどで設定済みなら追加設定は不要です。
3. `/admin/` に管理者パスワードでログインします。「サイト設定」→「非公開の棋譜データ」で、端末にある `kifu_data.json` を選び「棋譜データを登録」を押します。
4. トップページの「スコアアタックに挑戦する」から入り、ランダム対戦を開始します。会員ログイン中は会員ID、未ログイン時はHttpOnly Cookieのゲスト識別情報に成績をひも付けます。

保存先は `GOITA_PERSISTENT_DATA_DIR/private-kifu/kifu_data.json`、ローカルの設定なし環境では `private_data/kifu_data.json` です。登録は20MBまでで、再登録は検証後にファイルを置き換えます。通常の再デプロイ時には再登録不要です。バックアップは端末にも保持してください。

ファイル全体のダウンロードAPIは設けません。旧 `/static/kifu_data.json`・`/static/kifu_data_raw.json` も404にします。棋譜ID指定の手札読込も管理者専用APIから指定した1局の手札だけを取得します。リンクに手札を含める既存機能には変更ありません。

専用ルームは会員IDまたはゲストCookieで本人確認し、内部ルームIDが分かっても他人のHTTP・WebSocketアクセスを拒否します。公開の部屋一覧・プレイヤー一覧には掲載しません。別端末で同じ会員IDにログインして入室した場合は、A席の操作を入室した端末へ移します。

同じ人が再入室すると既存のルームを再利用します。表示中の再読み込みも自動復帰します。最終操作から15分でアクセスを終了し、15秒間隔の定期処理でもルーム・接続・AIの先読みを片付けます。盤面の取得、WebSocket接続、AIの手番は期限を延長しません。実際のクリック・キー入力・スクロールと手の送信が期限を更新します。未終了の対局は破棄しますが、初回挑戦済みの記録と終了済み成績は結果DBに残します。ルームはメモリ上のためサーバー再起動でも終了し、成績は永続DBから引き続き閲覧できます。

専用ルームでも他のルームと同じチャット欄と「AIに質問」を使えます。チャットAPIにも本人確認を適用します。

専用ルームでは、手札公開・席変更・Auto・持ち時間・配牌指定・任意ファイルからの開始などをHTTP API側でも禁止します。個人設定の表示・音は変更できます。開始メニューの説明文は省き、ランダム対戦と挑戦履歴への操作を中心に表示します。

トレースAIは、元棋譜の次の手が現在の合法手に含まれる間は、その手を優先して指します。A席の選択や別の条件によって局面が元棋譜から分岐した場合は、トレースを解除して通常AIへ切り替えます。これは棋譜から得られる手順と選択傾向の再現であり、元プレイヤーの内心や思考理由を完全に再現する機能ではありません。

終局時には、再戦結果のAC・BD累計点数と、読み込んだ棋譜の終了点数との差を表示します。入力された棋譜は解析と対戦開始のためにサーバーへ送信されますが、棋譜ライブラリには保存しません。通常ルームのメニューには表示されません。
外部形式で省略されているパスと、1行にまとめられた「受けてから攻める」手は、対局エンジンの手順に展開してから再生します。

## 結果・ランキング

終局をサーバーが確定すると、A席の挑戦者に結果ポップアップを一度表示します。点数は「今回 AC：20点」「元の対局 AC：50点」「元の対局との差 −30点」の順に表示します。「元々の棋譜を見る」は元の対局の行の右側に置き、モバイルでは同じ行の点数の下に折り返します。ペアの補足と挑戦回数の説明は表示しません。元棋譜画面は上部の「← 元々の棋譜を見る」で結果に戻ります。

履歴の上部は「← スコアアタックの挑戦履歴・ランキング」で開始メニューへ戻り、結果の上部は「← スコアアタックの結果」で履歴へ戻ります。履歴一覧は文字を一段階小さく表示し、挑戦回数の列を省いて、日付・課題番号・点差・結果ボタンを狭い間隔で並べます。課題ごとのランキングの名前には初回・2回目の区別を残します。

結果表示中は自動次局を停止します。開始メニューの「挑戦履歴・ランキング」で過去の終了済み挑戦を30件ずつ新しい順に確認でき、各記録から結果・元の棋譜・ランキングを開けます。履歴内の課題番号は表示専用で、原本の棋譜IDは公開しません。挑戦日・対戦日は日本時間の年月日だけを表示します。

改善点は `(今回AC獲得点 − 今回BD獲得点) − (元AC獲得点 − 元BD獲得点)`。開始時の持ち点を除きます。例：元がAC 0/BD 30、今回がAC 40/BD 0なら+70点。棋譜原本の獲得点も手順をエンジンで再生して確定します。

配牌（並び順は無視）・親・開始点数・元の手順が同じ局で比較します。AIはcurrentに統一し、同点は同順位（1位・1位・3位）。ランキングは終了済みの全挑戦を点差の大きい順に並べ、上位100件を表示します。同じ人でも「名前（初回）」「名前（2回目）」として別の行に記録します。自分の行には「（自分）」の目印が付きます。日時は年月日のみです。途中終了した挑戦はランキングに載せませんが、その棋譜の挑戦回数には含みます。

「ベスト記録／初回記録」の切り替えと「同じ棋譜でもう一度挑戦」は画面から削除し、直接の再挑戦APIも廃止します。ランダム選出は過去に挑戦した棋譜や直前の棋譜も対象に含めます。既存の成績・挑戦回数を保持し、過去の複数回の成績もランキングに表示します。以前のランキング集計方式は古いクライアント向けの参照用として残し、新しい結果APIの既定は全挑戦です。

終局後の卓上ボタンは「リセット」です。得点をクリアして待機状態に戻り、次のランダム対戦を選べます。結果・ランキングは残します。全棋譜を合算する総合ランキングはありません。

「元々の棋譜を見る」はライブラリ共通の盤面描画・再生処理を使用します。終局した挑戦の本人だけが、その1局の匿名化した手順を取得できます。進行中・他人の記録・他の部屋からのアクセスを拒否し、原本全体を公開するAPIはありません。本人専用ルームでは観戦できません。既存のデバッグルームは従来の共有ルームのままです。

保存先は `GOITA_PERSISTENT_DATA_DIR/private-kifu/trace-results.sqlite3`、ローカルは `private_data/trace-results.sqlite3`。既存の永続保存先で自動作成され、データ再登録・追加環境変数は不要です。会員の結果は期限なし、ゲストの結果は各終局から30日、未完了のゲスト挑戦は開始から30日で期限切れです。期限切れは即座に閲覧・ランキング対象から外し、定期処理（1時間ごと）でも削除します。ゲストの不要な識別情報と参照のない棋譜コピーも削除します。初回対戦前の再入室に使うゲストセッションは最終入室・対戦開始から30日で削除します。閲覧のたびに成績の期限を延長しません。

ブラウザ変更やCookie削除後のゲスト同一性は保証できません。保存期間内に残る同じ棋譜の挑戦履歴がある間は再挑戦扱いです。表示名はランキング表示用で、識別には使いません。会員ID・ゲスト識別子をランキングへ公開しません。ランキングの表示名は、次の挑戦開始時に現在の名前へ更新します。


## デイリー・ウィークリーランキング

トップページの「ランキングを見る」で、ルームに入らずに集計ランキングを開きます。初期表示はデイリーで、ウィークリーと切り替えられます。ログインや挑戦経験がなくても閲覧でき、閲覧だけではルームやゲスト識別Cookieを作成しません。名前・ゲスト表示・点数・対戦数を表示し、識別できる本人の行には自分の目印を付けます。会員ID、識別トークン、棋譜原本や対戦IDは返しません。

デイリーは日本時間の0時〜翌日0時に終了した全挑戦について、元の対局との差（improvement）を会員IDまたはゲスト識別情報ごとに合計します。マイナスを含みます。ウィークリーは月曜日0時〜翌月曜日0時で、まず日ごとの合計点差を計算し、日計がマイナスなら0点にして7日分を合計します。例：月曜＋50・火曜−70・水曜＋30なら週間80点です。今日が＋30から−20へ変わると、今日の週間加算分は30から0へ変わります。プラスの対戦だけの加算や日中の最高点ではありません。

日付の判定は開始時刻ではなくサーバーが記録した終局時刻です。未終了の挑戦は点数・対戦数とも対象外です。課題や挑戦回数によらず既存の終了済み成績も集計します。ゲスト30日の削除方針は従来どおりです。同点は同順位で、上位100人を表示します。0点・マイナスでも対戦済みの人を掲載します。期間は現在の日・週のみで、表示時にDBから再計算します。追加の環境変数やデータ移行コマンドは不要です。
