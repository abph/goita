# 結果が分かれた棋譜への挑戦

スコアアタック開始メニューの通常開始ボタンの下に専用の入口を表示する。
採点・AI・ランキング・報酬の仕組みは通常のスコアアタックと共通。

## 自動抽出

- 終局済みの `ranked=1` の記録を使用し、同じ参加者・課題は1件にする。
- ゲストの保存期限が過ぎた記録、再挑戦、練習、未完了の挑戦は含めない。
- 初回挑戦者が3人以上、最高点と最低点の差が50点以上、四分位範囲が20点以上。
- 四分位数はソートした点差の `(件数 - 1) * 割合` の位置を線形補間する。
- 上記に合う課題と、既存の現在利用可能な棋譜候補を照合してからランダムに選ぶ。
  要確認・除外・不正・範囲外・現在のアーカイブにない棋譜を復活させない。
- 条件を満たす棋譜がない場合は案内を表示し、通常開始へ自動で切り替えない。

開始時に毎回集計するため、固定の棋譜リストや追加の定期処理は不要。
3人の結果は偏りやすく、「戦略的に面白い」と保証する指標ではない。

## 終了後の比較

専用入口から開始した挑戦は `trace_attempts.selection_mode=divergent` として保存。
過去の履歴から開いても比較を表示できる。既存記録は `random` として保持する。

結果APIは本人の終局を確認した後にのみ、ほかの参加者の初回結果を匿名で返す。
本人の全挑戦を除外し、点差ごとの人数でまとめる。表示時点の有効な記録を使用するため、
その後の挑戦やゲスト記録の期限切れによって分布は変化する。
ほかの参加者の記録がすべてなくなった場合は比較欄を表示しない。

通常の初回・再挑戦判定は変更しない。この入口で同じ棋譜を引いても初回には戻らない。

## 確認

`tests/test_divergent_score_attack.py` で人数・点差・ばらつきの境界、再挑戦・期限切れ等の除外、
匿名比較、通常開始、所有者制御、開始前の結果非公開、既存の得点計算を確認する。
