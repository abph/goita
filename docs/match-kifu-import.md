# 複数局の棋譜読み込み

マイページ → 棋譜ライブラリ →「棋譜を読み込んでサーバーに保存」で自分の席を選び、YAMLファイルを読み込みます。複数局を含むファイルは各局を独立した棋譜として保存します。自分の席・メモ・タグは全局に適用します。

一覧にはファイル名（タイトル指定がある場合はそのタイトル）と「第N局」を表示します。同時に読み込んだ棋譜は第1局から順に並び、詳細には元のタイトルと全局数を表示します。各局の配牌・手順・名前・開始時と終了時の点数を保持します。

対応する外部形式は `version: 1.0`、共通の `p0`～`p3` と `log` 内の複数の `hand` / `uchidashi` / `score` / `game` です。複数局形式の `score` は局の開始点数として扱い、各局の得点と次局の開始点数の連続性を検証します。手順の「王」が実際には手駒の「玉」である場合は「玉」に補正します。従来の単局ファイルの点数解釈は維持します。

全局の再現と保存可能件数を確認してから、1トランザクションで保存します。不正な局や容量不足があれば部分保存せず、エラーを表示します。10局なら保存枠を10件使用します。DBの追加設定・移行操作は不要です。
