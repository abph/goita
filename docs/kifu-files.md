# 棋譜ファイル

トップページとルーム内のメニューに「棋譜ファイル」を配置します。個人設定の棋譜保存欄は撤去します。

- 棋譜を保存：終局した現在の部屋の棋譜を端末に保存します。
- 棋譜を匿名で保存：プレイヤー名を匿名にして端末に保存します。
- 棋譜を読み込んで見る：ログイン不要で単局・複数局のYAMLを一時表示します。局選択、最初・戻る・再生／停止・進む・最後の操作が使えます。

最大200KBのファイルを `/kifu/preview` に送信し、既存の棋譜解析・合法手チェックで検証します。レスポンスは `Cache-Control: no-store` とし、この処理は会員棋譜DB・対局状態・分析データへ書き込みません。読み込みはネット接続が必要です。ポップアップを閉じると読み込んだ棋譜と再生状態を破棄し、未完了リクエストを中止します。元のファイルは変更しません。

保存済みの会員棋譜の表示・編集とは独立した盤面を使用します。DB移行や追加の環境変数は不要です。
